# Sebastian Cosentino — Personal Portfolio

A React + TypeScript + Vite single-page portfolio designed with a light Technical Editorial direction.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/`.

## GitHub Pages

The repository is intended to be `slcosentino1.github.io`. The Vite base path is `/` and the GitHub Actions workflow in `.github/workflows/deploy.yml` builds and deploys `dist/` on pushes to `main`.

## Content

- Selected work: Autonomous Engineering Harness and AskDoc
- Professional case: AXA platform modernization (non-confidential summary)
- End-to-end engineering approach
- Professional experience, education and contact links
